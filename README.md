## 🖱️ 基本操作

*   **移动窗口**：鼠标**左键按住**窗口任意空白处，即可拖拽到屏幕任意位置。
*   **缩放窗口**：使用**鼠标滚轮**。
 *   向上滚：放大窗口和字体。
 *   向下滚：缩小窗口和字体。
 *   *✨ 智能缩放：字体大小会随窗口比例同步变化，且设有最小/最大字号限制，确保永远清晰可读。*
*   **右键菜单**：在窗口任意位置点击**鼠标右键**，可唤出功能菜单。

## ⚙️ 个性化设置

通过**右键菜单**选择 `⚙️ 设置薪资` 打开设置窗口：

| 设置项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| **月薪 (元)** | 你的税前或税后月薪，用于计算日薪和秒薪 | 5300 |
| **每日工作时长** | 每天实际工作的小时数，影响“每秒进账”的计算速度 | 7 |

*   **配置持久化**：修改并保存后，配置会自动存入同级目录下的 `niuma_config.json` 文件。**重启软件后设置依然有效**，无需重复输入。

## 📊 界面信息解读

1.  **顶部状态栏**：实时显示当前工作状态。
 *   💪 **搬砖中**：处于工作时间段内，金额实时跳动。
 *   😴 **休息中**：非工作时间段（如午休、下班后、周末）。
 *   🆓 **节假日**：自动识别法定节假日，显示“免费劳动力上线”。
2.  **中间绿色大字**：**今日实时收益**。仅在工作时间段内累计。
3.  **下方黄色中字**：**本月累计收益**。包含本月已过工作日的总薪资 + 今日实时收益。
4.  **底部灰色小字**：
 *   `本月 X 个工作日`：根据日历自动计算当月应出勤天数。
 *   `每秒进账 ¥X.XXXX`：根据你的月薪和工时计算出的“摸鱼单价”。
